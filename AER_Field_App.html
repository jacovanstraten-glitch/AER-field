About

Version

AER Field App — Phase 1 + 2. Records inspections and photos (like qc_app3) and batch changes (harvest, location, pots, plants/pot, step status). Exports inspections as CSV + photos, and batch changes as a separate batch_edits CSV (ready for the Phase 3 sync into AER_Data.xlsx). The inspection CSV format is unchanged, so your existing OneDrive import keeps working.

Tip: open this file in Chrome and choose "Add to home screen" to use it as an app (works offline).
